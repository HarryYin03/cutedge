HOW TO ADD PROJECT THUMBNAILS
=============================

1. Save your project thumbnails here
2. Recommended size: 600x400 pixels (or similar 3:2 aspect ratio)
3. Formats: .jpg, .png, .webp
4. Name them descriptively (no spaces):
   - fitness-brand.jpg
   - gaming-intro.png
   - restaurant-promo.webp

5. In Work.tsx, reference them as:
   thumbnail: '/projects/fitness-brand.jpg'

TIP: You can screenshot your Instagram posts or use the original video thumbnails.
